Detailed Description

Generic key-value context store for scripting and internal utilities.

HTTP handlers should prefer MantisRequest::set and MantisRequest::getOr for per-request attributes (auth, verification, etc.). This store is used where a standalone typed bag is needed outside the request lifecycle.
