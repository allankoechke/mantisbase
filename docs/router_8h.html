Detailed Description

HTTP router: route registration, schema cache, CORS, and built-in API endpoints.

Bridges MantisBase handler/middleware chains (MbRouteRegistry) to Drogon's HTTP server. Also owns MbSSEMgr (SSE + WebSocket realtime) and the entity schema cache used on every CRUD request.
