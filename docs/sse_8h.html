Detailed Description

Server-Sent Events (SSE) manager for the realtime API.

Exposes GET and POST /api/v1/realtime:

  • GET /api/v1/realtime — Opens an SSE connection (optional topics query). Returns client_id in the connected event.
  • POST /api/v1/realtime — Sets topics for an existing session (JSON body: client_id, topics, optional token). Returns granted topics and denied entries.

Authentication is optional at connect; invalid tokens are treated as guest. MbAuth can be upgraded on POST subscribe but not downgraded or switched to another user.
