Detailed Description

JSON value carried into a Duktape method without going through nlohmann::json.

dukglue stores arguments in std::tuple via std::forward_as_tuple. Converting tuple<json&&> to tuple<json> constructs the json from that tuple, and nlohmann::json serializes a tuple as a one-element array. MbScriptJson is not constructible from a tuple, so the argument is moved through unchanged.
