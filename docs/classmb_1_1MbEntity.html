Detailed Description

Represents a database table/entity with schema and CRUD operations.

MbEntity provides methods to interact with database tables including creating, reading, updating, and deleting records. It encapsulates schema information and access rules.

auto app = MantisBase::create();
json schema = {{"name", "users"}, {"type", "base"}, {"fields", json::array()}};
MbEntity entity(*app, schema);
// Or by name after the schema exists in the database:
MbEntity users = app->entity("users");

Construct entity from schema JSON object, bound to its app.

The app is injected at construction so every MbEntity is always bound to the services (database, realtime) its CRUD operations need — there is no separate bind step to forget. Copies carry the binding.
