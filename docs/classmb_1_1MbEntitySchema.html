Detailed Description

Builder class for creating and managing database table schemas.

MbEntitySchema provides a fluent interface for defining table structures, fields, access rules, and converting to/from JSON and DDL.

auto app = MantisBase::create();
MbEntitySchema schema(*app, "users", "base");
schema.addField(MbEntitySchemaField("name", "string").setRequired(true));
schema.addField(MbEntitySchemaField("email", "string").setIsUnique(true));
schema.setListRule(MbAccessRule("auth", "", "users"));
MbEntity entity = schema.toEntity();

mb::MbEntitySchema::MbEntitySchema ( const MantisBase & app)
explicit

Construct an empty schema bound to its application.

Used by the fromSchema()/fromEntity() builders before fields are added. The app is injected at construction so DDL/validation can always reach the database without a separate bind step to forget.

Parameters
appOwning application. Stored non-owning; must outlive the schema.
