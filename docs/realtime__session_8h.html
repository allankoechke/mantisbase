Detailed Description

Shared auth, topic filtering, and session helpers for SSE and WebSocket realtime.

Implements the PocketBase-style two-phase realtime model:

  • Connect: optional credentials; invalid tokens become guest.
  • Subscribe: re-resolve token, upgrade auth, filter topics by entity list/get rules.

Token precedence (realtime only): ?token= query param overrides Authorization: Bearer. Session IDs use the prefixes rt_sse_ and rt_ws_.
