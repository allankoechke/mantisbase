Detailed Description

JWT token creation and verification utilities.

Provides static methods for generating and validating JWT tokens used for authentication and authorization.

auto app = MantisBase::create();
auto& auth = app->auth();
json claims = {{"id", "user123"}, {"table", "users"}};
std::string token = auth.createToken(claims, 3600); // 1 hour
json result = auth.verifyToken(token);
if (result["verified"].get<bool>()) {
std::string userId = result["id"];
}
// API keys and OAuth live on the same MbAuth instance:
auth.apiKey().create("users", "user123", "Mobile app");
auth.oauth().buildAuthorizeUrl("users", "google", redirect_uri);

◆ requestLoginOtp()

json mb::MbAuth::requestLoginOtp ( const std::string & entity_name,
const std::string & email ) const
nodiscard

Email a one-time sign-in code for an auth-entity account.

The code expires after 10 minutes and allows 5 attempts. A successfully delivered code replaces any earlier code for that account. When the address is valid, unknown emails return { "sent": true } and no message is sent. A message is delivered only when an account with that email exists.

Parameters
entity_nameAuth entity table name.
emailAccount email address.
Returns
JSON object { "sent": true }.
Exceptions
MbException400 when SMTP is not configured or the address is invalid.
MbExceptionwhen delivery fails (rate limit or SMTP error).
