Detailed Description

HTTP request wrapper bound to a MantisBase instance.

Per-request attributes (auth, verification, etc.) are stored on the underlying Drogon request via set() / get(), not a global context. Use mbApp() (from MbAppMixin) to reach application services.

◆ jsonBody()

const json & mb::MbRequest::jsonBody ( ) const
nodiscard

Unified parsed request body (lazy, parsed once per request).

This is the single body entry point for (req, res) handlers on PUT/PATCH/POST, covering both JSON and multipart/file-upload bodies.

JSON requests: the parsed body; throws MbException(400) on malformed JSON. Multipart requests: empty until parseFormDataToEntity() maps the form fields onto an entity.

For a non-throwing parse use bodyAsJson().
