Detailed Description

Non-owning access to the active MantisBase from DI-aware types.

MbEntity, MbRouter, MbRequest, MbApiKeyMgr, MbOAuthMgr, and other framework types inherit this mixin so handlers and services can call mbApp() instead of a removed global singleton.

router.Get("/api/v1/stats", [](MbRequest& req, MbResponse& res) {
auto count = req.mbApp().entity("posts").countRecords();
res.sendJSON(200, {{"posts", count}});
});
